# 咨询级商业视觉设计

一个用于商业封面与信息图的可复用 Skill。通过**文字重构、单一商业隐喻和白蓝灰视觉系统**，生成理性、克制、结构清晰的最终画面。

## 适用场景

- **封面**：X、PPT、商业报告、作品集、公众号。
- **信息图**：咨询分析页、方法论图、流程图、矩阵图。

封面强调低信息密度与单一视觉中心；信息图强调明确阅读路径、3–6 个主要模块和一个核心结构。不用于普通整套演示文稿或纯文字商业分析。

## 核心规则

- 长标题拆为主视觉核心词、完整标题与少量分类标签，保留用户原始主题。
- 从 15 类商业隐喻中选择一个最贴合主题的主隐喻，嵌入字形或信息结构。
- 使用白底、深蓝、黑色与冷灰，克制使用强调色、细线、网格和编号。
- 严格限制无关装饰、模板感、密集图标、不可读文字与伪造数据。
- 成功时直接展示最终画面，不输出分析过程；工具不可用或关键约束无法满足时说明限制。

## 使用示例

```text
使用 $consulting-business-visuals
主题：从流量增长到价值增长
用途：PPT封面
画幅比例：16:9
语言：中文
补充语境：面向企业管理层，强调长期价值与增长质量
禁用元素：人物、机器人、霓虹光效
直接生成最终画面。
```

```text
使用 $consulting-business-visuals
主题：从客户需求到价值交付
用途：流程图
画幅比例：16:9
语言：中文
补充内容：需求识别、方案设计、交付执行、反馈优化
不添加未经提供的数据，直接生成最终画面。
```

副标题、行业背景、目标受众、情绪倾向和禁用元素均可按需补充。

## 执行与验证边界

此 Skill 提供视觉规格与工作流程，需要使用环境具备可用的图像生成工具。它不包含账号凭据，不自动安装工具或启动额外付费调用，也不保证图像工具一次正确呈现全部文字。

目前已完成文件结构、YAML 配置、引用和隐喻数量检查，尚未进行实际出图测试。生成后仍应检查标题、术语、数据、阅读顺序与文字可读性。
