# 通用商业隐喻选择库

按主题实际语义选择一个主隐喻。封面不叠加多个隐喻；信息图允许围绕一个主隐喻展开子模块。

| 主隐喻 | 适合表达 | 文字融合方向 |
| --- | --- | --- |
| 漏斗 | 筛选、转化、收敛、用户路径、销售流程、机会识别 | 笔画或负空间逐渐收束，阶段线进入字形 |
| 路径 | 战略推进、方法论、增长路线、行动计划、转型进程 | 路径沿笔画延伸或穿过字内空间 |
| 阶梯 | 升级、价值提升、能力进阶、商业成熟度、定价层级 | 基线或文字模块逐级提升 |
| 矩阵 | 定位、比较、选择、竞争格局、优先级判断 | 网格成为字形骨架或文字的区块结构 |
| 坐标 | 市场地图、战略定位、机会区间、风险收益关系 | 坐标轴和区间嵌入标题，并清晰标注维度 |
| 飞轮 | 增长循环、复利机制、网络效应、持续运转系统 | 字形与循环轨迹共享结构，保留循环方向 |
| 节点网络 | 系统协同、组织连接、技术架构、资源关系 | 节点连接文字笔画并表达关系 |
| 数据流 | 信息流动、自动化、效率提升、输入输出关系 | 流线从字中穿入穿出，明确输入输出 |
| 门槛 | 准入、筛选、风险控制、阶段关口、决策标准 | 字内设置可辨识的阈值或通过边界 |
| 窗口 | 市场机会、时间窗口、突破口、趋势入口 | 字形开口或负空间构成窗口 |
| 防线 | 风险管理、治理机制、合规控制、安全边界 | 边界线与字形共同构成保护或分隔结构 |
| 断层 | 结构变化、代际变化、产业转折、认知差距 | 局部切割或错位呈现断裂，仍保持可读 |
| 容器 | 价值承载、商业模式、资源池、收益池 | 字形或框架形成承载空间 |
| 罗盘 | 方向选择、战略判断、长期定位、路径导航 | 方向轴或指向结构嵌入文字 |
| 建筑结构 | 组织架构、能力底座、系统搭建、治理框架 | 笔画成为支撑、层级、底座或结构框架 |

## 语义取舍

- 增长：扩张、上升、飞轮或复利；按增长机制选择，不把任何增长都画成飞轮。
- 转化：收敛、筛选、漏斗或路径。
- 战略：路径、坐标、分叉决策或罗盘。
- 系统：模块、链路、节点或建筑架构。
- 风险：阈值、防线、断层或分级。
- 市场：坐标、窗口、区块或竞争格局。
- 价值：阶梯、刻度、容器或交换。
- 效率：压缩、加速、流动或自动化。
- 机会：开口、窗口、突破点或增长通道。
- 组织：层级、重组、协作网络或治理结构。

这些是选择线索，而不是新增隐喻数量配额。只有主题确实包含循环机制时才用飞轮；只有比较维度明确时才用矩阵或坐标；单纯顺序不应被暗示成复利或因果。
